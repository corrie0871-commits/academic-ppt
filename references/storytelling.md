# 场景、论证与讲述

| 场景 | 优先回答 | 内容取舍 |
|---|---|---|
| 课程展示 | 是否回答题目、满足评价要求、论据可靠 | rubric 映射优先；不要把论文的字数要求误当演示要求 |
| 学术会议 | 研究解决什么问题，新增了什么证据 | 背景只保留理解关键结果所需部分；结果和贡献优先 |
| 毕业答辩 | 为什么这样研究，结论能站得住吗 | 保留方法选择理由、替代解释、局限；细节移到允许的备份页 |
| 文献汇报 | 原作者做了什么、证据多强、哪里可质疑 | 原论文结论与汇报人的评论清楚区分 |
| 阶段汇报 | 已有证据是什么、尚未完成什么 | 计划不能包装成结果；明确下一步与验证条件 |

通用论证链：现实或理论问题 → 已知与未知 → 研究问题 → 为什么这个方法能回答 → 关键证据 → 回答与适用边界。它是检查逻辑的框架，不是固定七页模板。

城市或社会研究可采用“场所/人群 → 分析框架 → 空间或访谈证据 → 发现 → 含义”；设计建议必须标明它是建议，不能写成已经验证的改善效果。理论论文以概念区分、推导和反例为核心，不强塞实验结果。

10 分钟的初始时间预算可用：问题和背景 1.5 分钟、方法 1.5、核心证据 4、讨论与结论 2、转场 1。随复杂度与 rubric 调整；如时长含问答先扣除问答。按每页讲稿估时再调整，不靠页数猜时间。

讲稿示例结构：“这张图比较了什么。先看哪个轴/哪组。主要差异在哪里。这支持怎样的有限结论。下一页回答什么。”不能从视觉上看似不同就声称统计显著。

准备问题时关注具体研究：抽样偏差、测量方式、缺失数据、方法替代、适用地区/人群、因果识别、负向证据。回答分为：直接回答 → 论文依据 → 尚不能回答的边界。
